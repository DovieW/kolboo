# Kolboo 0.3.1

A maintenance release focused on desktop startup, window sizing and reliable text insertion.

- Added **Start at login** in Settings → UI. This is a per-computer setting and is off by default.
- Fixed undersized main windows on Linux desktops with fractional display scaling. Window size and maximized state now survive restarting Kolboo and reopening it from the tray.
- Reuse a keyboard-only desktop permission session on Wayland and securely restore it after restarting, where the desktop supports persistent approval. Revoked permissions, an unavailable keyring or unsupported desktop integrations can still require approval again.
- Keep the transcript available in the clipboard when automatic insertion is unavailable. Prevent delayed permission approvals from inserting text belonging to an older recording.
- Reduced repeated macOS Accessibility prompts within a running session.

Community and bring-your-own-key features remain usable without a Kolboo account. Linux updates remain manual. Windows and macOS native acceptance for this maintenance release is deferred; the macOS download remains experimental.
