# Linux Community beta

- Added installable x86_64 Linux packages for Ubuntu/Kubuntu: a Debian package and a portable AppImage.
- Added account-free Community and bring-your-own-key model discovery, including refreshable provider/model data from models.dev.
- Improved Linux global shortcuts, focus preservation, Wayland clipboard fallback, and recording-overlay placement.
- Improved account onboarding and made managed versus bring-your-own-key model selection explicit.
- Added safer diagnostics and Sentry integration that exclude transcripts, prompts, audio, credentials, and authorization headers.

This beta is intended for Community/BYOK use. Managed service behavior, native Wayland text injection, automatic updates, and architectures other than x86_64 are not part of the initial Linux support scope.
