# Initial release of the Kolboo fork

## Highlights

- Removed requirement for separate python server.
- Added a full profile system to control AI settings per context.
- Overlay improvements: waveform/UX overhaul, clearer states (transcribing/rewriting).
- Improved settings UX.
- Added/expanded provider support (including Google, Anthropic, OpenAI, AssemblyAI, Avalon, Speechmatics and more).
- Added full request/response logging.
- Added cost stats and data management actions (including delete-data controls).
- And lots more.
