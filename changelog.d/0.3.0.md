# Kolboo 0.3.0

- Added a compact Home recorder for dictation and longer meetings, with pause and resume, local recovery, and optional computer audio on Linux.
- Added file transcription with a model picker and optional speaker labels. Long recordings are processed in bounded uploads and combined into one History item.
- Redesigned History with expandable recordings, waveform playback, a full transcript view, search, title and text corrections, and retry for failed recordings.
- Added custom OpenAI-compatible providers for bring-your-own-key transcription and language models. Provider keys remain in the operating system's secure storage.
- Added local Activity and Models usage views, while keeping estimated API spend separate for Community users.
- Improved Linux program-profile discovery and configurable paste shortcuts, along with microphone selection and recording-overlay behavior.
- Added privacy-scoped product analytics and more useful, content-minimized crash diagnostics. Basic usage events begin only after the in-app disclosure is reviewed; linked analytics remain optional.

Community and bring-your-own-key features remain usable without a Kolboo account. Computer-audio capture and program discovery depend on desktop-platform capabilities; not all Linux desktop environments expose the same integrations.
