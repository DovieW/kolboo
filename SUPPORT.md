# Support

## Getting help

- For bugs and feature requests: open a GitHub issue.
- For questions: use GitHub Discussions or open an issue labeled “question”.

## Before filing a bug

Please include:

- your OS + version
- Kolboo version
- steps to reproduce
- relevant logs (redacted)

## Security issues

If you believe you found a security issue, please do not file a public issue. Follow `SECURITY.md`.
