# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

- Contact the maintainer(s) via GitHub (for example, ping `@DovieW`) and ask for a private channel to share details.

When reporting, please include:

- Kolboo version
- OS and any relevant environment details
- steps to reproduce
- expected vs actual behavior
- impact assessment (what could an attacker do?)

## What to expect

- We’ll acknowledge receipt as soon as practical.
- We’ll work on a fix and, when appropriate, publish a release.

## Security notes (app-specific)

- Kolboo can record microphone audio and may send audio/transcripts to third-party providers depending on your settings.
- Do not include sensitive audio, transcripts, API keys, or Authorization headers in public bug reports.

For user-facing privacy/data details, see `docs/User Docs/PRIVACY_AND_DATA.md`.
