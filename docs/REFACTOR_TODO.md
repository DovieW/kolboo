# Refactor ideas (out of scope) — index

This used to be one big “parking lot” file. It’s now split into multiple docs so you (Dovie) can quickly see what’s worth doing soon vs later.

## How this is split

- **High-impact (schedule/plan):** reduces risk (settings breakage, Rust/TS drift), improves correctness, or unlocks deterministic tests.
  - See: `docs/Refactors/1_HIGH_IMPACT.md`

- **Medium-priority (opportunistic):** great to do when you’re already working in the area, or during a cleanup window.
  - See: `docs/Refactors/2_MEDIUM_OPPORTUNISTIC.md`

- **Low-urgency (polish/preference):** quality-of-life ideas that are easiest to defer.
  - See: `docs/Refactors/3_LOW_POLISH.md`
