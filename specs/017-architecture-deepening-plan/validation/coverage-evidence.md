# Coverage Evidence: Architecture Deepening Plan

## Gate

Every changed or newly introduced in-scope module must reach:

- 100% statement coverage
- 100% branch coverage
- 100% function coverage
- 100% documented edge-case coverage
- regression coverage for every defect discovered during implementation

Default validation must not require real network calls, API keys, paid accounts, audio hardware, screenshots, timing sleeps, or user interaction.

## Required commands

### TypeScript

- Format/lint before tests: `pnpm -C app lint`
- Unit tests: `pnpm -C app test`
- Coverage: `pnpm -C app coverage`

### Rust

Before Cargo commands in PowerShell:

- Use `sccache` when available via `RUSTC_WRAPPER=sccache`.
- Clear `RUSTC_WRAPPER` when `sccache` is unavailable.
- Set `CARGO_BUILD_JOBS` to about half logical cores, capped at 8.

Package scripts added during US8:

- `coverage:evidence` — parses coverage output and emits in-scope evidence.
- `cargo:coverage` — runs deterministic Rust in-scope coverage through `app/scripts/rust-coverage.mjs`.
