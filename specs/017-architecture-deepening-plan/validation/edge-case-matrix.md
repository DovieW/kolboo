## Coverage-gate validation examples

| Example                                              | Deterministic check                                        | Expected result                                               |
| ---------------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------- |
| Missing in-scope TypeScript file in coverage summary | `evaluateCoverage(summary, ["src/missing.ts"])`            | Fails with `missing`                                          |
| Branch coverage below 100%                           | `evaluateCoverage(summary, ["src/fail.ts"])`               | Fails with `branches`                                         |
| Rust coverage helper argument construction           | `buildRustCoverageArgs(...)`                               | Emits deterministic `cargo llvm-cov` arguments                |
| Existing Cargo job limit                             | `createRustCoverageEnvironment({ CARGO_BUILD_JOBS: "3" })` | Preserves caller-provided limit                               |
| Coverage helper CLI entrypoint on Windows            | `isCliEntrypoint(fileUrl, scriptPath)`                     | Direct script execution is detected and cannot silently no-op |
