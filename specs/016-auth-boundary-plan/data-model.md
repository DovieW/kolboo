# Data Model: Identity-Policy Boundary for Desktop Auth

## Entity: IdentitySession

- **Description**: Authenticated desktop session context persisted across launches.
- **Fields**:
  - `session_id` (string, required)
  - `subject_id` (string, required) — stable user identity key
  - `issuer` (string, required)
  - `access_token_expires_at` (datetime, required)
  - `refresh_token_present` (boolean, required)
  - `storage_state` (enum: `stored_securely` | `missing` | `write_failed`, required)
  - `last_refresh_at` (datetime, optional)
- **Validation rules**:
  - `subject_id` must be non-empty and issuer-qualified for multi-IdP safety.
  - `access_token_expires_at` must be in the future at session activation time.
- **State transitions**:
  - `signed_out` → `active` after successful PKCE completion + secure storage write.
  - `active` → `degraded` when token expired and refresh fails.
  - `active|degraded` → `signed_out` on logout or session clear.

## Entity: AccessToken

- **Description**: IdP-issued bearer token used for edge authorization.
- **Fields**:
  - `token_value` (string, required, secret)
  - `iss` (string, required)
  - `aud` (string, required)
  - `sub` (string, required)
  - `exp` (unix timestamp, required)
  - `nbf` (unix timestamp, optional)
  - `jti` (string, optional)
- **Validation rules**:
  - Signature must validate against trusted JWKS.
  - `iss`, `aud`, and `exp` must match environment policy.
  - If present, `nbf` must be satisfied with allowed clock skew.

## Entity: OrganizationMembership

- **Description**: Product authorization record mapping user identity to org-level access.
- **Fields**:
  - `org_id` (string, required)
  - `subject_id` (string, required)
  - `role` (enum: `member` | `admin` | `owner`, required)
  - `tier` (enum: `community` | `personal` | `enterprise`, required)
  - `entitlements` (set<string>, required)
  - `policy_version` (string, optional)
  - `status` (enum: `active` | `suspended` | `revoked`, required)
- **Validation rules**:
  - Exactly one active membership context applies per managed request.
  - `revoked` or `suspended` status must deny managed operations.

## Entity: PolicyDecision

- **Description**: Deterministic authorization outcome generated by edge for a requested operation.
- **Fields**:
  - `decision_id` (string, required)
  - `subject_id` (string, required)
  - `org_id` (string, optional)
  - `operation` (string, required)
  - `result` (enum: `allow` | `deny`, required)
  - `reason_code` (enum: `reauth_required` | `insufficient_tier` | `policy_denied` | `membership_missing` | `token_invalid`, required)
  - `evaluated_at` (datetime, required)
- **Validation rules**:
  - `reason_code` required for all deny outcomes.
  - Decision must be auditable and reproducible from request context + policy snapshot.

## Entity: UsageRecord

- **Description**: Metering record for managed operations used for quotas/billing/audit.
- **Fields**:
  - `usage_id` (string, required)
  - `subject_id` (string, required)
  - `org_id` (string, optional)
  - `operation` (string, required)
  - `units` (number, required)
  - `meter_window` (string, required)
  - `recorded_at` (datetime, required)
- **Validation rules**:
  - Created only when policy decision is `allow`.
  - Must be idempotent for retried edge operations.

## Entity: TokenExchangeTriggerSet

- **Description**: Governance object that determines when token exchange must be adopted.
- **Fields**:
  - `multi_idp_required` (boolean, required)
  - `kill_switch_required` (boolean, required)
  - `embedded_claims_required` (boolean, required)
  - `desktop_idp_agnostic_required` (boolean, required)
  - `reviewed_at` (datetime, required)
  - `decision` (enum: `direct_idp_token` | `adopt_token_exchange`, required)
- **Validation rules**:
  - `decision` must be `adopt_token_exchange` if any trigger field is true.
  - Every decision must include review timestamp for auditability.
